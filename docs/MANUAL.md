# RecR 操作マニュアル (Ver1.0)

RecR は radiko.jp のラジオ放送を録音する Windows デスクトップアプリです。このページでは各タブ・各メニューの使い方を説明します。

## 起動

配布された `RecR.exe`（`dist/RecR/` フォルダ内）を実行するか、ソースから起動する場合は以下のコマンドを使用します。

```bash
python src/main.py
```

起動時にエリア判定を行い、視聴可能な放送局の一覧を取得します。

## 画面構成

ウィンドウ上部にメニューバー、その下に5つのタブ（録音／番組表／予約録音／フリーワード／保存先フォルダ）があります。ライブ再生中は画面下部にイコライザー（スペクトラムまたはピークメーター）が表示されます。

## 録音タブ

- **ステーション選択**: 一覧から放送局を選択します。選択すると自動的にライブ再生が始まります。
- **録音設定**: 録音時間（分）を指定して「録音開始」を押すと、その場で録音を開始します。
- 録音中はステータス表示で残り時間を確認できます。「録音停止」でいつでも中断できます。

## 番組表タブ

- ラテ欄形式のグリッドで、選択中の複数局・最大10日分の番組表を表示します（サムネイル付き）。
- 上部の切り替えで表示モードを選べます:
  - **番組表**: 通常の番組表（当日〜先の予定分）
  - **過去7日間（タイムフリー）**: 選択中の局の、過去7日間に放送済みの番組を表示
- 「番組表」モードで番組をダブルクリックすると:
  - 放送中の番組 → 即時録音を開始
  - 未来の番組 → 予約録音を作成
  - 放送終了済みの番組 → タイムフリー取得の確認ダイアログを表示（下記「タイムフリー」参照）
- 「過去7日間（タイムフリー）」モードでは、番組をダブルクリックするとタイムフリー取得の確認ダイアログを表示します。
- 「番組表を一括更新」（メニューの「番組表」から）で全局分を再取得できます。
- 番組表は自動的にキャッシュされ、設定した「自動更新しきい値」を超えると再取得されます。

## タイムフリー

- 放送終了済みの番組は、確認ダイアログで「はい」を選ぶとタイムフリー（radikoの聴取期限付き見逃し配信）からダウンロードできます。
- radikoのタイムフリーは放送から概ね1週間で聴取期限が切れるため、期限切れの番組はダイアログでその旨が表示され、取得できません。
- 同時にダウンロードできる件数には上限があります（既定3件、メニュー →「設定」→「タイムフリー同時ダウンロード数...」で1〜10件に変更可能）。上限に達している間は新規ダウンロードを開始できません。
- ダウンロード中の番組は、右上の「現在録音中／タイムフリー取得中」パネルに進捗（ダウンロード済みセグメント数）とともに表示されます。
- ダウンロードが完了・失敗・中断すると、システムトレイ通知でお知らせします（データを取得できなかった場合や通信エラーで中断した場合は警告として表示されます）。
- アプリ終了時、タイムフリー取得中の番組がある場合は「終了すると中断されます」という確認が表示されます。

## 予約録音タブ

- 登録済みの予約を一覧表示します。
- 予約は「1回のみ」または「毎週繰り返し」で作成できます（番組表タブから登録）。
- 各予約は個別に有効/無効を切り替え可能で、一括切り替えにも対応しています。
- 複数局を同時に録音する予約も設定できます。
- 不要な予約は選択して削除できます。
- 「タイムフリー」列: 予約が失敗・中断した場合や、実行時刻を過ぎても待機中のまま取りこぼした場合に「⬇ ダウンロード」と表示されます。クリックするとその回をタイムフリーで取り直せます（既にタイムフリーで取得済みの予約には表示されません）。
- 取りこぼした予約がある場合、起動のたびに一度だけ通知で知らせます。

## フリーワードタブ

- キーワードを登録しておくと、番組名・概要・出演者を対象に全局横断で自動検索します。
- 検索対象局はキーワードごとに指定できます。
- ヒットした番組はプレビューで内容を確認したうえで、そのまま予約に登録できます。

## 保存先フォルダタブ

- 現在の録音保存先フォルダの中身を一覧表示します。
- 保存先の変更は メニュー →「設定」→「録音保存先...」から行います（既定値は `%USERPROFILE%\Music\RecR\`）。

## メニュー

### ファイル
- **終了**: アプリケーションを終了します。

### 表示
- **ライトテーマ / ダークテーマ**: sv-ttk の配色を切り替えます。
- **イコライザー表示**:
  - スペクトラム（マルチバンド）
  - ピークメーター（アナログ針風）

### 番組表
- **番組表を一括更新**: 全局分の番組表を再取得します。

### 設定
- **録音品質**:
  - フォーマット: AAC（再エンコードなし）／ M4A（再エンコードなし・タグ対応）／ MP3
  - MP3 選択時はビットレートを選択可能
- **録音ファイル名の形式**: 局名_日付_時刻／日付_時刻_番組名／日付_番組名／番組名_日付_時刻／番組名_日付 から選択
- **録音保存先...**: 保存先フォルダを変更
- **起動時のデフォルト局**: アプリ起動時に自動選択される局を指定
- **番組表の取得日数...**: 番組表を何日分先まで取得するか設定
- **番組表の自動更新しきい値...**: キャッシュが何日経過したら自動再取得するか設定
- **全局自動更新の時刻...**: 全局一括更新を自動実行する時刻を設定
- **タイムフリー同時ダウンロード数...**: タイムフリーを同時にいくつまでダウンロードできるようにするかを設定（1〜10、既定3）
- **予約録音の前後マージン**: 予約録音の開始・終了時刻の前後に足す余白秒数を設定（なし／15秒／30秒／45秒／60秒）。番組表の時刻と実際の配信のわずかなズレで冒頭・末尾が欠けるのを防ぎます
- **予約待機中・録音中は自動スリープを抑止する**: チェックを入れると、有効な予約がある間・録音中はWindowsのアイドルによる自動スリープを止めます（既定でオン）。詳細は [スリープ対策](#スリープ対策) を参照

## システムトレイ

- ウィンドウを閉じてもタスクは終了せず、システムトレイに常駐します（予約録音を継続するため）。
- トレイアイコンを右クリックすると「表示」「終了」を選択できます。
- 録音の開始・完了などはトレイ通知でお知らせします。

## スリープ対策

- 有効な予約が1件でもある間、または録音中は、Windowsの**アイドルによる自動スリープ**を抑止します（`SetThreadExecutionState` API使用）。これにより、放置してPCが自動スリープしたことで予約が実行されない、という事態を防ぎます。
- この機能は メニュー →「設定」→「予約待機中・録音中は自動スリープを抑止する」のチェックでオン/オフを切り替えられます（既定でオン）。
- ただし以下の場合は対象外です。抑止できるのは「放置による自動スリープ」だけで、ユーザー自身の明示的な操作は止められません。
  - ユーザーがスタートメニューやノートPCの蓋閉じ等で**手動でスリープ・休止**を選んだ場合
  - **休止状態（S4）**に入った場合（休止はプロセスごと停止するため、アプリ側からは制御できません）
- 手動スリープ・休止から復帰した場合、開始時刻から**3分以内**の復帰であれば遅れて録音を開始しますが、3分を超えると該当回はスキップされます（通知なし）。予約録音を確実に行いたい場合は、電源設定で「一定時間操作がない場合にスリープする」を無効にしておくことをおすすめします。

## よくある質問

**Q. 録音が始まらない**
A. インターネット接続と、選択中の放送局がお住まいのエリアで配信対象かを確認してください。radiko はエリア判定に基づいて配信可否が決まります。

**Q. 過去の番組を録音したい**
A. 番組表タブで終了済みの番組をダブルクリックするか、「過去7日間（タイムフリー）」モードから対象の番組をダブルクリックすると、タイムフリーでダウンロードできます。ただし放送から概ね1週間で聴取期限が切れるため、それ以前の番組は取得できません。詳細は [タイムフリー](#タイムフリー) を参照してください。

**Q. 予約したのに録音されなかった**
A. 予約の有効/無効設定、アプリ（またはトレイ常駐）が起動していたか、PCがスリープしていなかったかを確認してください。

**Q. 録音した音源を配布してもいい？**
A. できません。radiko の利用規約により、録音は個人の私的利用の範囲に限られます。詳細は [README のライセンス・免責事項](../README.md#免責事項) を参照してください。
